# silent-isle-mini

Terraform · Vue

折腾中的小玩具

## 用法

```bash
cat data.txt | node index.js
```

输出：

```

---

```

## 安装

```bash
git clone https://github.com/USER/silent-isle-mini.git
cd silent-isle-mini
npm install
```
